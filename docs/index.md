# FastAPI-Fin

FastAPI-Fin 是 Dishka 與 FastAPI 之間的契約組裝層。服務先定義介面，模組宣告 exports 和 requires，組裝點才選擇實作。FastAPI 管理路由、驗證與 OpenAPI；Dishka 管理依賴作用域與清理。
